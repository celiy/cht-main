Cargos:
    - Nova estrutura:
        Permissões Mecarvit: manter tabela cargo + usuario.cargo_id + fundador/superadmin fora da lista.

    - Permissões de visualização:
        Novo modelo de permissão de acesso. Existem as partes principais do sistema como funcionários, clientes, veículos, ordens de serviço e registros financeiros. No caso de uso atual onde um funcionário é um mecânico comum, ele só teria acesso às ordens de serviço, mas se a gente limitar o cargo atual apenas a isso, na visualização de uma OS, ele pode ver dados sensiveis como o CPF de um funcionário e etc.

        Para cada àrea do sistema, existe um set de qual permissão um funcionário tem. Para funcionários, um usuário pode ter a permissão apenas de visualização, ou pode ter também de edição/cadastro e exclusão.

        Um funcionário que só tem permissão de visualização de funcionários pode ver apenas o nome deles e nada mais. Mesma coisa para um cliente, o funcionário pode ver apenas o nome dele. Visualização de um veículo deixa o funcionário ver qualquer dado do veículo. Se um cargo receber apenas a permissão de visualização, ele não poderá ver a área no frontend de visualização por entidade mas ele pode ver esses dados em outra parte tipo na visualização de uma OS. Mesma coisa se aplica aos registros, visualização de um registro financeiro apenas permite que o funcionário possa ver o valor de uma OS, não acessar a área diretamente.

        Agora, se um funcionário poder editar/criar (um cargo não pode apenas cadastrar ou editar, ele tem que poder fazer os dois) uma entidade, então aquela entidade aparece pra ele no frontend.

        Se ele tiver permissão de exclusão aí ele só normalmente poderá excluir/desativar uma entidade. Um usuário não pode ter apenas a função de exclusão sem ter a de criar/editar primeiro.

        Agora, tem uma fragmentação maior, só poder criar/editar uma entidade não significa que o funcionário pode ver dados sensíveis como o CPF/CNPJ. Um acesso a uma entidade pode receber o nivel de Gerente, onde ele tem as permissões de ver, editar e excluir mas ele é considerado alguém de maior confiança, então ele pode editar e visualizar estes dados mais sensíveis.

        Uma nova permissão chamada exportação é usada para poder exportar pada PDF os dados de uma tabela.

        Apenas superadmin pode resetar senha de funcionários.

        Apenas superadmin pode ter acesso aos logs do sistema.

        Pré criar para todo sistemas cargos pré configurados que podem ser editados apenas pelo superadmin:
            Gerente: Acesso a todas entidades do sistema, visualizar/editar/cadastrar dados normais e sensíveis, exclusão e ativação/desativação.

            Mecanico: Acesso apenas à visualização e edição de ordens de serviço. Com estas permissões ao acessar a página de ordens de serviço o botão de cadastrar não deve aparecer, o menu de ação deve mostrar apenas as opções de visualizar e editar. Ao editar/visualizar uma ordem de serviço, deve ser visivel apenas o nome do cliente, dados do veículo, status, diagnóstico do cliente e mecânico (ele deve poder apenas alterar o diagnóstico do mecânico), visualizar apenas os serviços e seus valores, os valores abaixo, não pode visualizar/editar pagamentos, pode editar as observações e visualizar as datas de criado/modificado.
